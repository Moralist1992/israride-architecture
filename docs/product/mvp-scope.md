# MVP Scope

This document defines the minimum viable product (MVP) for Israride.

---

## 🎯 Goal

The MVP should validate the core functionality of a ride-hailing platform in a regulated environment.

---

## 🚗 Core Features

### Passenger Side

- Create ride request  
- Define pickup and destination  
- View estimated price  
- Track ride status  

---

### Driver Side

- Toggle availability (online/offline)  
- Receive ride requests  
- Accept or reject rides  
- Complete rides  

---

## 🔄 Ride Lifecycle

The system must support a basic ride flow:

requested → accepted → in progress → completed  

---

## 🔐 Authentication

- Passenger accounts  
- Driver accounts  
- Role-based access  

---

## 🧩 Backend Requirements

- REST API  
- Ride storage (database)  
- User management  
- Basic pricing calculation  

---

## ⚠️ Out of Scope (MVP)

- Advanced surge pricing  
- Complex driver ranking  
- Payment integrations  
- Real-time scaling optimizations  

---

## 📌 Notes

This scope is intentionally minimal to validate the product concept and core user flows.
