# Quick Start

This guide shows how to quickly understand and simulate a basic ride flow in the Israride system.

---

## 🚀 Basic Flow

1. Open the application  
2. Select your role:
   - Passenger  
   - Driver  

---

## 👤 Passenger Flow

1. Enter pickup location  
2. Enter destination  
3. Review estimated price  
4. Create ride request  

---

## 🚗 Driver Flow

1. Set status to "Online"  
2. Receive ride request  
3. Accept or reject request  
4. Start ride  
5. Complete ride  

---

## 💰 Pricing

The system calculates ride cost based on:

- distance  
- time  
- applied fees  

📄 See: `../api/pricing.md`

---

## 🔄 Ride Lifecycle

requested → accepted → in progress → completed  

📄 See: `../flows/pickup-flow.md`

## 📌 Notes
