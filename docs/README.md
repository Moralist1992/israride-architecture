# Israride — Technical Documentation

This repository contains the technical documentation for **Israride**, a ride-hailing platform built for a future legal market in Israel where private drivers can operate transportation services legally.

The system is designed as a transparent and regulation-ready alternative to traditional platforms like Uber.

---

## 🚗 About the Project

Israride focuses on a different economic and pricing model:

- transparent pricing (distance + time + regulatory fees)
- no commission per ride
- subscription-based access for drivers
- adaptability to evolving regulation

The platform is designed with a strong emphasis on clarity, modularity, and system transparency.
